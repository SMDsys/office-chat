# Офис-чат

Корпоративный чат для небольшого офиса: один исполняемый файл на сервере,
веб-интерфейс в браузере, без интернета и внешних сервисов.

Рассчитан на 15–50 человек в локальной сети. Windows 10/11 на сервере,
любой современный браузер на клиентах.

## Возможности

- Общий канал, свои каналы, личные сообщения.
- Файлы и изображения до 50 МБ, перетаскивание в окно.
- Ответы-цитаты, реакции, редактирование и удаление, закреплённые сообщения.
- Поиск по истории, счётчики непрочитанных, «печатает…», статус «в сети».
- Упоминания `@логин` и `@all`: автодополнение в поле ввода, подсветка,
  отдельный звук и значок `@` у чата.
- Уведомления на рабочем столе, когда вкладка свёрнута; кнопка «Отметить всё
  прочитанным».
- Звук новых сообщений, тёмная и светлая темы.
- Регистрация по логину и паролю; первый зарегистрировавшийся — администратор.
- Админка: список сотрудников, сброс пароля, блокировка и журнал действий.
- Работа как службы Windows с автозапуском, ежедневные резервные копии.
- HTTPS с самоподписанным сертификатом — одной настройкой.

## Быстрый старт (Windows)

1. Скачайте `OfficeChat-*-win64.zip` со страницы [Releases](../../releases).
2. Распакуйте в `C:\OfficeChat`.
3. Запустите `install.bat` от имени администратора.
4. Откройте `http://localhost:8080` и зарегистрируйте первый аккаунт.
5. Передайте сотрудникам адрес из строки «В локальной сети».

Подробная инструкция для сотрудников и администратора — в `README.txt`
внутри архива.

## Сборка из исходников

Нужен Go 1.27+.

```bash
git clone https://github.com/SMDsys/office-chat.git
cd office-chat

# для текущей системы
go build -o officechat .

# для Windows без CGO
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -trimpath -ldflags "-s -w" -o dist/OfficeChat.exe .
```

Запуск для проверки:

```bash
./officechat -port 8099 -data /tmp/officechat-data
```

Веб-интерфейс встроен в бинарник через `go:embed`, отдельные файлы для
запуска не нужны.

## Настройка

`config.json` рядом с исполняемым файлом:

```json
{
  "port": 8080,
  "host": "0.0.0.0",
  "dataDir": "data",
  "tls": false
}
```

| Поле | Значение |
|---|---|
| `port` | порт, по умолчанию 8080 |
| `host` | `0.0.0.0` — все интерфейсы, `127.0.0.1` — только этот компьютер |
| `dataDir` | папка данных относительно `.exe` |
| `tls` | включить HTTPS |
| `tlsCert`, `tlsKey` | свои сертификат и ключ (PEM); если не заданы, создаётся самоподписанный в `data/tls/` |

Флаги командной строки переопределяют конфиг:

```
-tls                 включить HTTPS
-tls-cert, -tls-key  свои сертификат и ключ
-port, -data         порт и папка данных
-passwd логин:пароль сменить пароль (при остановленной службе)
-install, -uninstall служба Windows
-version             версия
```

### HTTPS

```json
{ "tls": true }
```

При первом запуске создаётся самоподписанный сертификат для `localhost`
и всех IP-адресов компьютера. Браузер покажет предупреждение — его нужно
подтвердить один раз на каждом компьютере.

Самоподписанный сертификат защищает от прослушивания трафика в сети, но не
от активной подмены. Для строгой проверки укажите `tlsCert`/`tlsKey` от
внутреннего или публичного удостоверяющего центра.

## Данные

```
data/
  users.json          сотрудники
  channels.json       каналы
  chats/*.json        история сообщений
  uploads.json        метаданные файлов
  uploads/<id>        сами файлы
  sessions.json       активные входы
  server.log          журнал
  backups/*.zip       резервные копии (раз в сутки, 10 последних)
  tls/                сертификат и ключ, если включён HTTPS
```

Резервная копия включает переписку и вложения. Для полной копии можно
остановить службу и скопировать всю папку `data/`.

Устаревшие сессии и файлы, загруженные без сообщения, удаляются
автоматически.

## Устройство

| Файл | Назначение |
|---|---|
| `main.go` | конфигурация, маршруты, запуск, остановка |
| `store.go` | JSON-хранилище, сообщения, сессии, копии, уборка |
| `api.go` | HTTP API |
| `audit.go` | журнал действий администратора |
| `auth.go` | PBKDF2, cookie, ограничение попыток входа |
| `hub.go` | WebSocket, онлайн-статусы, рассылка событий |
| `files.go` | загрузка и выдача файлов |
| `tls.go` | самоподписанный сертификат |
| `service_windows.go` | служба Windows |
| `web/` | клиент: HTML, CSS, JS без сборки |

Пароли хранятся как PBKDF2-HMAC-SHA256, 120 000 итераций. Сессия — в
HttpOnly-cookie на 30 дней. Запросы с чужим `Origin` отклоняются.

## Ограничения

- Только локальная сеть; выход в интернет не требуется и не настраивается.
- Интерфейс рассчитан на настольный браузер.
- Нет видеозвонков и федерации с другими серверами.
