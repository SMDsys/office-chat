# Офис-чат

Корпоративный чат для небольшого офиса: один исполняемый файл на сервере,
веб-интерфейс в браузере, без интернета и внешних сервисов.

Рассчитан на 15–50 человек в локальной сети. Windows 10/11 на сервере,
любой современный браузер на клиентах.

## Возможности

- Общий канал, свои каналы, личные сообщения.
- Закрытые каналы: видны только участникам; состав ведёт создатель или админ.
- Файлы и изображения до 50 МБ, перетаскивание в окно.
- Фото профиля и статусы: «в сети», «отошёл», «не беспокоить»;
  при 10 минутах бездействия статус переключается сам.
- Ответы-цитаты, реакции, редактирование и удаление, закреплённые сообщения.
- Поиск по истории, счётчики непрочитанных, «печатает…», статус «в сети».
- Упоминания `@логин` и `@all`: автодополнение в поле ввода, подсветка,
  отдельный звук и значок `@` у чата.
- Уведомления, когда вкладка свёрнута: системные всплывашки по HTTPS
  (в остальных случаях — внутри вкладки и счётчиком в заголовке);
  кнопка «Отметить всё прочитанным».
- Тихие чаты: для каждого канала и личной переписки — «все сообщения»,
  «только упоминания» или «тихо»; непрочитанные считаются.
- Ссылка на сообщение: кнопка копирует адрес, при открытии чат
  переключается на нужное место и подсвечивает сообщение.
- Звук новых сообщений, тёмная и светлая темы.
- Экспорт переписки канала в HTML для чтения или JSON для архива.
- Регистрация по логину и паролю; первый зарегистрировавшийся — администратор.
- Админка: список сотрудников, сброс пароля, блокировка, назначение
  администраторов и журнал действий.
- Работа как службы Windows с автозапуском, ежедневные резервные копии
  и восстановление из копии.
- HTTPS с самоподписанным сертификатом — одной настройкой.

## Быстрый старт (Windows)

1. Скачайте `OfficeChat-*-win64.zip` со страницы [Releases](../../releases).
2. Распакуйте в `C:\OfficeChat`.
3. Запустите `install.bat` от имени администратора.
4. Откройте `http://localhost:8080` и зарегистрируйте первый аккаунт.
5. Передайте сотрудникам адрес из строки «В локальной сети».

Подробная инструкция для сотрудников и администратора — в `README.txt`
внутри архива.

## Сборка из исходников

Нужен Go 1.27+.

```bash
git clone https://github.com/SMDsys/office-chat.git
cd office-chat

# для текущей системы
go build -o officechat .

# для Windows без CGO
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -trimpath -ldflags "-s -w" -o dist/OfficeChat.exe .
```

Запуск для проверки:

```bash
./officechat -port 8099 -data /tmp/officechat-data
```

Веб-интерфейс встроен в бинарник через `go:embed`, отдельные файлы для
запуска не нужны.

## Настройка

`config.json` рядом с исполняемым файлом:

```json
{
  "port": 8080,
  "host": "0.0.0.0",
  "dataDir": "data",
  "tls": false
}
```

| Поле | Значение |
|---|---|
| `port` | порт, по умолчанию 8080 |
| `host` | `0.0.0.0` — все интерфейсы, `127.0.0.1` — только этот компьютер |
| `dataDir` | папка данных относительно `.exe` |
| `tls` | включить HTTPS |
| `tlsCert`, `tlsKey` | свои сертификат и ключ (PEM); если не заданы, создаётся самоподписанный в `data/tls/` |

Флаги командной строки переопределяют конфиг:

```
-tls                 включить HTTPS
-tls-cert, -tls-key  свои сертификат и ключ
-port, -data         порт и папка данных
-passwd логин:пароль сменить пароль (при остановленной службе)
-restore файл.zip    восстановить данные из резервной копии
-force               перезаписать существующие данные при -restore
-install, -uninstall служба Windows
-version             версия
```

### HTTPS

```json
{ "tls": true }
```

На уже установленном чате проще запустить `Включить HTTPS.bat` от имени
администратора: он поставит `"tls": true` и перезапустит службу.

При первом запуске создаётся самоподписанный сертификат для `localhost`,
имени компьютера и всех его IP-адресов. Если адрес компьютера изменится,
сертификат пересоздастся при следующем запуске.

Браузер покажет предупреждение — его нужно подтвердить один раз на каждом
компьютере. Чтобы убрать предупреждение и включить системные уведомления
в Chrome и Edge, добавьте сертификат в доверенные:

1. На сервере возьмите `data/tls/cert.pem` — он создаётся при первом
   запуске с HTTPS.
2. На каждом компьютере положите `cert.pem` рядом с
   `Доверять сертификату.bat` и запустите скрипт от имени администратора
   (или просто перетащите `cert.pem` на скрипт).
3. Закройте все окна браузера и откройте чат заново: адрес с `https://`
   откроется с зелёным замком.

Убрать доверие можно так же — скриптом `Убрать доверие.bat`.

Сертификат пересоздаётся, когда у сервера меняется IP-адрес: после этого
новый `cert.pem` нужно раздать и установить на компьютерах заново. Поэтому
серверу лучше выдать постоянный IP.

HTTPS нужен для системных уведомлений: браузеры дают их только в защищённом
контексте. Firefox показывает их и с самоподписанным сертификатом, Chrome
и Edge могут блокировать — тогда чат показывает уведомления внутри вкладки
и счётчик в заголовке. Совсем без предупреждений работает сертификат
внутреннего или публичного удостоверяющего центра: укажите `tlsCert`/`tlsKey`.

## Данные

```
data/
  users.json          сотрудники
  channels.json       каналы
  chats/*.json        история сообщений
  uploads.json        метаданные файлов
  uploads/<id>        сами файлы
  avatars/<id>.<ext>  фото профиля
  sessions.json       активные входы
  server.log          журнал
  backups/*.zip       резервные копии (раз в сутки, 10 последних)
  backups/uploads/<id> зеркало вложений — одно на все копии
  tls/                сертификат и ключ, если включён HTTPS
```

Резервная копия включает переписку и метаданные файлов; сами вложения
хранятся в `backups/uploads` в одном экземпляре, а не в каждой копии.
Для полной копии можно остановить службу и скопировать всю папку `data/`.

Восстановление — при остановленной службе:

```
OfficeChat.exe -restore D:\backups\officechat-20260101-030000.zip -data C:\OfficeChat\data -force
```

Вложения берутся из папки `uploads` рядом с архивом (то самое зеркало),
уже существующие файлы не перезаписываются.

Устаревшие сессии и файлы, загруженные без сообщения, удаляются
автоматически.

## Устройство

| Файл | Назначение |
|---|---|
| `main.go` | конфигурация, маршруты, запуск, остановка |
| `store.go` | JSON-хранилище, сообщения, сессии, копии, уборка |
| `api.go` | HTTP API |
| `audit.go` | журнал действий администратора |
| `avatar.go` | фото профиля |
| `export.go` | экспорт переписки в HTML и JSON |
| `restore.go` | восстановление данных из резервной копии |
| `auth.go` | PBKDF2, cookie, ограничение попыток входа |
| `hub.go` | WebSocket, онлайн-статусы, рассылка событий |
| `files.go` | загрузка и выдача файлов |
| `tls.go` | самоподписанный сертификат |
| `service_windows.go` | служба Windows |
| `web/` | клиент: HTML, CSS, JS без сборки |

Пароли хранятся как PBKDF2-HMAC-SHA256, 120 000 итераций. Сессия — в
HttpOnly-cookie на 30 дней. Запросы с чужим `Origin` отклоняются.

## Ограничения

- Только локальная сеть; выход в интернет не требуется и не настраивается.
- Интерфейс рассчитан на настольный браузер.
- Нет видеозвонков и федерации с другими серверами.
